3. Coba akses berkas langsung lewat URL browser
   Jawab: saya nyoba buka file lewat URL http://kampuslms-kelompok-a07.test/storage/submissions/1/0RmruW1xozlyFx935vL1a58ElFUrjy6MQARXzMnu.pdf, tapi hasilnya muncul HTTP 404 Not Found, ini karena `URL /storage/` mengarah ke folder `storage/app/public`, sedangkan file tugas tadi tersimpan di `storage/app/private`. jadi file tsb memang ga bisa diakses langsung lewat URL itu. kalau mau mengunduh, pengguna harus lewat controller aplikasi yang mengatur akses file tersebut

4. Apa beda disk local dan public di config/filesystems.php?
   Jawab: disk local mengarah ke folder `storage/app/private` dan ga punya URL publik, jadi file yang disimpan di sana cuma bisa dibaca melalui kode PHP di server. sedangkan disk public mengarah ke folder `storage/app/public` dan punya konfigurasi `URL 'url' => env('APP_URL').'/storage'`. jadi file yang disimpan di disk public bisa diakses langsung lewat web server seperti Nginx atau Apache tanpa harus diproses melalui PHP, bedanya file di local bersifat privat, sedangkan file di public bisa diakses langsung melalui URL publik

5. Apa fungsi perintah php artisan storage:link?
   Jawab: perintah `php artisan storage:link` fungsinya membuat symbolic link dari folder `public/storage ke storage/app/public`. jadi file yang ada di folder `storage/app/public` bisa diakses lewat `URL /storage`. makannya file pengumpulan tugas mahasiswa ga boleh disimpan di folder tsb, karena orang bisa mengunduhnya langsung tanpa harus login atau melewati pengecekan hak akses dari aplikasi. proses ini juga ga ngelewatin pengecekan sesi atau Policy, jadi file tugas lebih aman disimpan di folder privat dan diakses melalui controller yang ngatur hak akses pengguna
